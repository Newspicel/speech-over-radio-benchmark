# Speech over Radio Benchmark

Compares speech denoisers on audio received over radio: NFM, AM and SSB, with hiss,
threshold clicks, fading, static crashes and heterodynes.

- **Synthetic:** 228 LibriSpeech sentences through 19 simulated links (48 min).
  Clean reference and transcript for every clip.
- **Real:** 286 clips (70 min). Off-air recordings, airband ATC with transcripts,
  and LibriSpeech sent over real HF links (clean reference available).

77 methods, 18 of them chains. Run on 2026-10-03, Apple Silicon Mac, commit `ef27836`.
This file is generated by `uv run sorb report`.

## Findings

- Best Whisper WER: `dpdfnet-dpdfnet2_8khz-12dB`, 25.1 % (input 28.3 %). 68 of 76 methods make WER worse than doing nothing.
- Best WER per mode: NFM `sdrmm-dpdfnet8_8khz` (7.2 %), AM `sdrmm-dpdfnet8_8khz` (43.1 %), SSB `dpdfnet-dpdfnet2_8khz-12dB` (10.0 %).
- Best PESQ-NB: `sdrmm-dpdfnet8_8khz`, 2.36 (input 1.75). Best ESTOI: `dpdfnet-dpdfnet8_8khz`, 0.583 (input 0.429).
- DPDFNet 16 and 48 kHz models delete radio speech (-50 to -74 dB). The 8 kHz models keep it (-2.9 dB). Upstream does the same, so it is the model, not the SDR-- port.
- SDR-- neural output is 40 to 44 ms later than `latency()` reports.
- The SDR-- auto-notch removes speech (-16.6 dB, WER 81.9 %). Its 4-sample delay makes voiced speech predictable. With a 2 ms delay (`lms-notch`) speech stays (-0.7 dB).
- Fading AM: a sync detector alone takes WER from 76.9 % to 46.5 %, more than any denoiser.
- Real recordings, best SNR gain with speech kept: `sdr#-ninr-lp-comm-narrow→sdrmm-dpdfnet8_8khz`, +20.2 dB.
- Speech deleted on real recordings: `autonotch→deepfilternet3`, `dpdfnet-dpdfnet4`, `dpdfnet-dpdfnet8_48khz_hr`, `sdrmm-dpdfnet4`, `sdrmm-dpdfnet8_48khz_hr`.

## Limitations

- Whisper is trained on noisy audio and dislikes denoiser artifacts. Read WER next to ESTOI.
- DNSMOS expects wideband speech, so radio scores low overall.
- VAD can mislabel very noisy audio.
- ATC transcripts use their own conventions; compare ATC WER between methods only.

## Run

```sh
uv sync
(cd tools/sdrmm-denoise && cargo build --release)
uv run sorb all
```

Steps, all cached:

```sh
uv run sorb corpus      # download and build the test sets
uv run sorb process     # run methods, -m takes names or globs
uv run sorb score       # PESQ, ESTOI, SI-SDR, DNSMOS, levels
uv run sorb asr         # Whisper WER
uv run sorb speed       # RTF per stage
uv run sorb level       # DPDFNet input level test
uv run sorb report      # rewrite this README
```

SDR# NINR needs your own SDR# copy:

```sh
tools/setup_ninr.sh
export SORB_SDRSHARP=/path/to/sdrsharp-x86-next
uv run sorb process -m 'sdr#*'
```

Audio is cached as 16 kHz FLAC in `data/`, models in `models/`.
